【公開担当者の方へ】

このフォルダの「index.html」が射的ゲーム本体です。
HTML・CSS・JavaScript・3D描画コードを1ファイルにまとめています。
外部画像・外部ライブラリはありません。

■ Web公開するとき
1. index.html を静的Webサイトのトップページとしてアップロードしてください。
2. 公開後の https://... のURLをQRコードにしてください。
3. iPad / タブレットでQRを読み、SafariまたはChromeで動作確認してください。

■ PCで中身を確認するとき
・index.html を右クリック →「プログラムから開く」→ Microsoft Edge / Google Chrome
・Windowsでは START_WINDOWS.bat をダブルクリックしても開けます。

■ 注意
・ゲームはWebGL2を使います。古いブラウザや、学校PCのセキュリティ設定でWebGL2/JavaScriptが無効な場合、USB上でのローカル実行はできないことがあります。
・ローカルで開けなくても、公開サーバーへ index.html をアップロードできれば公開作業自体は可能です。
・ファイル名は index.html のまま使うのがおすすめです。
・Windowsで「index.html.txt」になっていないことを確認してください。

【依頼者向け】
USBには、このフォルダまたはZIPファイルをそのままコピーして渡してください。
